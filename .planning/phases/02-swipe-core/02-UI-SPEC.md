# Phase 2 — UI Design Contract: Swipe Core

> Visual and interaction contract for the swipe loop UI. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Platform: React Native (Expo SDK 52) — StyleSheet only. No CSS, no shadcn. All values in device-independent pixels (dp).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (React Native StyleSheet) |
| Preset | not applicable |
| Component library | none — hand-rolled with RN primitives |
| Icon library | Unicode symbols inline in Text (✕ ⭐ ♥ ⏱ ↩) — no icon library installed |
| Font | System default (San Francisco on iOS, Roboto on Android) |
| Theme | Dark-only for v1 — the swipe screen is a standalone dark surface within the otherwise light app |

**Note on theme split:** Phase 1 screens (auth, playlist pickers) use a light theme (`#fff` background, `#f9fafb` list surface). Phase 2's swipe screen introduces a dedicated dark surface. This is intentional — music consumption UI follows Spotify/Apple Music conventions. The two themes coexist in the app: light for navigation/list screens, dark for the swipe session.

---

## Spacing Scale

All values are multiples of 4dp. Used consistently in all Phase 2 components.

| Token | Value | Usage in Phase 2 |
|-------|-------|-----------------|
| xs | 4dp | Icon-to-label gap, badge internal padding |
| sm | 8dp | Card inner text gap (title↔artist), button bar inter-button gap |
| md | 16dp | Card horizontal text padding, screen horizontal padding, modal padding |
| lg | 24dp | Card bottom text area vertical padding, modal section spacing |
| xl | 32dp | Button bar top/bottom margin from card bottom and screen bottom |
| 2xl | 48dp | Card top offset from safe area (space for destination edit button) |
| 3xl | 64dp | Button bar circle button diameter |

**Exceptions:**
- Button bar touch targets: minimum 44dp per axis (accessibility requirement) — the 64dp circle diameter satisfies this
- Card corner radius: 16dp (not on scale — visual quality exception)
- Swipe overlay icon size: 80dp (not on scale — readability exception during gesture)
- SegmentNavigator tap zone: 50% screen width × card height (fills card halves; not a spacing value)

## Typography

System font stack only. No custom font loading — reduces bundle size and avoids FOUT in React Native.

**Exactly 4 sizes. Exactly 2 weights.**

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display — track title | 22dp | 700 (bold) | 1.2 (26dp) | SwipeCard primary text — track name |
| Heading — modal title | 18dp | 700 (bold) | 1.2 (22dp) | DestinationEditor modal title |
| Body / UI label | 16dp | 400 (regular) | 1.5 (24dp) | Artist name, button labels, modal text, scope labels, cancel button |
| Caption | 12dp | 400 (regular) | 1.4 (17dp) | Album name, preview badge text, no-preview badge text, playback status, playlist track count |

**Weight mapping:** All former semibold (600) usages → 700. All former medium (500) usages → 400. No weights other than 400 and 700 are permitted anywhere in Phase 2.

**Rule:** Maximum 4 distinct sizes in any single component. SwipeCard uses: 22 / 16 / 12. ButtonBar uses: no labels (icon-only). DestinationEditor uses: 18 / 16 / 12.

## 1. Layout & Spacing

### Swipe Screen Layout

**Primary visual anchor: album art (full-card cover fill). Secondary anchor: track title (22dp bold, bottom-left of text area).**

```
┌──────────────────────────────┐  ← StatusBar (system)
│  [safe area top — 44–59dp]  │
├──────────────────────────────┤
│  [Destination Edit Button]  │  ← top-right, 44×44dp touch target
│                              │  ← positioned absolute, zIndex 10
│                              │
│       [Card Stack]           │  ← flex: 1, fills remaining space
│    (current card on top)     │    between destination button and button bar
│    (next card visible        │
│     beneath — slightly       │
│     scaled down)             │
│                              │
├──────────────────────────────┤
│  [Button Bar — 80dp tall]   │  ← fixed height, above safe area bottom
│                              │
│  [safe area bottom — 0–34dp]│
└──────────────────────────────┘
```

**Card Stack:**
- Card dimensions: `width = screenWidth - 32dp` (16dp horizontal margin each side), `height = screenHeight * 0.62` (empirical — fits card + button bar without overflow on 375×812 baseline)
- Card corner radius: 16dp
- Next card scale: 0.94 (uniform), positioned directly beneath current card (no Y offset needed due to scale)
- Next card opacity: 0.7 (fades slightly to reinforce depth)
- Card stack zIndex: current card = 2, next card = 1

**Destination Edit Button:**
- Position: absolute, top = safeAreaTop + 12dp, right = 16dp
- Size: 36×36dp icon button with 44×44dp touch target (transparent padding)
- Visual: pencil/edit icon (✏ Unicode) inside a pill: `backgroundColor: rgba(0,0,0,0.5)`, `borderRadius: 18dp`, `paddingHorizontal: 12dp`, `paddingVertical: 8dp`
- Label: small text "Destinations" at 12dp, weight 400, color `rgba(255,255,255,0.8)` — shown beside icon
- Full button reads: `✏ Destinations`

**Button Bar:**
- Container: `height: 80dp`, `flexDirection: row`, `justifyContent: space-evenly`, `alignItems: center`, `paddingHorizontal: 16dp`
- Background: `transparent` (screen background shows through)
- Button order (left to right): Undo → Skip → SuperLike → Like → DecideLater

### Card Internal Layout

```
┌────────────────────────────────┐
│                                │
│    [Album Art — full width]    │  ← flex: 1, cover-fill
│    [SegmentNavigator zones]    │  ← absolute overlay, left/right halves
│    [Swipe Direction Overlay]   │  ← absolute overlay, animated opacity
│                                │
│  [Gradient fade — bottom 30%] │  ← absolute, LinearGradient from transparent → #111
├────────────────────────────────┤
│ ♪ [Track Title]          [●●] │  ← 22dp bold + playback indicator
│   [Artist Name]               │  ← 16dp regular
│   [Album Name — optional]     │  ← 12dp — shown only if height > 520dp
│   [Preview Badge / Status]    │  ← 12dp caption, right-aligned or below
└────────────────────────────────┘
```

- Text area: `paddingHorizontal: 16dp`, `paddingVertical: 16dp`, background `#111111` (matches screen, feels like card extends)
- Gradient: covers bottom 30% of the art area, `colors: ['transparent', 'rgba(17,17,17,0.95)']` — ensures text legibility over any album art
- Text area height: fixed 88dp (22+8+16+8+12+16+6 — title, gap, artist, gap, badge, top/bottom padding)
- Total card height = art area + 88dp text area

## 2. Components

### SwipeCard

**Visual states and their exact treatment:**

| State | Album Art | Overlay | Badge / Label | Text |
|-------|-----------|---------|---------------|------|
| Loading (skeleton) | Gray shimmer `#2C2C2E` animated | None | None | Gray placeholder bars |
| Playing (Spotify Connect) | Full art | None | Animated playback dots (3×, green) | Normal |
| Playing (Preview mode) | Full art, slight desaturation | None | `PREVIEW` badge — yellow pill | Normal |
| No preview available | Full art, `opacity: 0.7` | None | `NO PREVIEW` badge — gray pill | Normal |
| Swiped right (like) | Full art | Green tint `rgba(29,185,84,0.35)` + `♥` icon 80dp | None | Normal |
| Swiped left (skip) | Full art | Red tint `rgba(255,59,48,0.35)` + `✕` icon 80dp | None | Normal |
| Swiped up (super like) | Full art | Blue tint `rgba(10,132,255,0.35)` + `⭐` icon 80dp | None | Normal |
| Decide Later | Full art | Yellow tint `rgba(255,214,10,0.35)` + `⏱` icon 80dp | None | Normal |

**Overlay:** absolute full-card overlay, `borderRadius: 16dp`, opacity driven by gesture translation (0 at rest → 1 at swipe threshold). Icon centered, font size 80dp.

**Playback indicator (playing state):** Three dots in a row, each 6dp diameter, 4dp gap. Active dot: `#1DB954`. The dots pulse via a looping Reanimated `withRepeat(withTiming(...))` — all three pulse in sequence with 150ms stagger. Shows in top-right of text area.

**Preview badge:** `backgroundColor: rgba(255,214,10,0.15)`, `borderColor: #FFD60A`, `borderWidth: 1dp`, `borderRadius: 4dp`, `paddingHorizontal: 8dp`, `paddingVertical: 4dp`. Text: `PREVIEW` in 12dp, weight 700, color `#FFD60A`. Position: bottom-right of art area (above gradient), or inline in text area.

**No preview badge:** Same shape as preview badge. `backgroundColor: rgba(255,255,255,0.08)`, `borderColor: rgba(255,255,255,0.2)`, `borderWidth: 1dp`. Text: `NO PREVIEW` in 12dp, weight 400, color `rgba(255,255,255,0.5)`.

**Skeleton state:** Use `#2C2C2E` placeholder for art area. Title placeholder: `width: 60%`, `height: 16dp`, `borderRadius: 4dp`, `backgroundColor: #3A3A3C`. Artist placeholder: `width: 40%`, `height: 12dp`, `borderRadius: 4dp`, `backgroundColor: #3A3A3C`. No animation in v1 (static shimmer is acceptable).

**Props interface:**

```typescript
interface SwipeCardProps {
  track: Track;
  playbackState: 'loading' | 'playing-connect' | 'playing-preview' | 'no-preview' | 'paused';
  swipeOverlay: 'none' | 'like' | 'skip' | 'super-like' | 'decide-later';
  overlayOpacity: number; // 0–1, driven by Reanimated shared value
  isNext?: boolean; // true for the background card — applies scale + opacity dimming
}
```

### ButtonBar

**Button anatomy:** Circular `TouchableOpacity`, diameter 64dp. Inner icon via `Text` (Unicode). Outer ring via `borderWidth: 2dp`, `borderColor` per action. Background: `rgba(255,255,255,0.05)`.

| Button | Label | Icon | Border color | Icon color | Icon size |
|--------|-------|------|-------------|------------|-----------|
| Undo | — | ↩ | `rgba(255,255,255,0.4)` | `#FFFFFF` | 24dp |
| Skip | — | ✕ | `#FF3B30` | `#FF3B30` | 26dp |
| Super Like | — | ⭐ | `#0A84FF` | `#0A84FF` | 26dp |
| Like | — | ♥ | `#1DB954` | `#1DB954` | 26dp |
| Decide Later | — | ⏱ | `#FFD60A` | `#FFD60A` | 24dp |

**Size hierarchy:** SuperLike and Like buttons are 72dp diameter (slightly larger — primary actions). Skip button is 64dp. Undo and Decide Later are 52dp (secondary actions). This creates a visual hierarchy that mirrors action importance.

**Press feedback:** `activeOpacity: 0.7` on TouchableOpacity. Do not use `Animated.spring` on button press — the lightweight opacity change is sufficient and does not conflict with gesture animations.

**Disabled state (Undo when undoStack is empty):** `opacity: 0.3`, `pointerEvents: none`.

**Props interface:**

```typescript
interface ButtonBarProps {
  onSkip: () => void;
  onLike: () => void;
  onSuperLike: () => void;
  onDecideLater: () => void;
  onUndo: () => void;
  canUndo: boolean; // false when undoStack is empty
  isDisabled?: boolean; // true while card snap animation is playing (isAnimating guard)
}
```

### SegmentNavigator

Invisible overlay on the SwipeCard art area. Two transparent `TouchableOpacity` zones, each covering 50% of the card width × 100% of the art area height.

- Left zone: `seek(-20s)` — no visible feedback (tap is for power users)
- Right zone: `seek(+20s)` — no visible feedback
- Conflict prevention: these zones receive taps, the GestureDetector receives pans. RNGH simultaneous gesture support handles the coexistence.
- Brief haptic feedback on seek (if `expo-haptics` is available — call `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light)`). Not blocking — wrap in try/catch.

## 3. Motion & Interaction

### Swipe Gesture

All values sourced from RESEARCH.md Pattern 1 (verified against Reanimated v3 docs).

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Commit threshold — horizontal | 30% of screenWidth | Standard Tinder-pattern; confirmed in RESEARCH.md |
| Commit threshold — vertical (up) | 120dp | Taller threshold to avoid accidental super likes |
| Velocity override | 500 dp/s | Fast flick commits regardless of distance |
| Max rotation | ±15 degrees | Proportional to horizontal travel; `rotation = (translateX / screenWidth) * 15` |
| Snap-off spring | `stiffness: 500, damping: 40, overshootClamping: true` | Snappy exit — overshoot off-screen feels wrong |
| Return spring | `stiffness: 300, damping: 30` | Gentle return to center — less jarring than snap |
| Snap target X (like) | `screenWidth * 1.5` | Off-screen right |
| Snap target X (skip) | `-screenWidth * 1.5` | Off-screen left |
| Snap target Y (super like) | `-800` | Off-screen top |

### Overlay Opacity Curve

The colored overlay (like/skip/super-like/decide-later) fades in proportionally to how far the card has traveled past the commit threshold.

```
overlayOpacity = clamp(
  translation / commitThreshold,
  0,
  1
)
```

- At 0% travel: opacity 0 (invisible)
- At 30% of threshold: opacity 0.3 (subtle tint begins)
- At 100% of threshold (commit point): opacity 1.0
- Above threshold: stays at 1.0

Direction detection for overlay color:
- `translateX > 0` → like overlay (green)
- `translateX < 0` → skip overlay (red)
- `translateY < 0 AND |translateY| > |translateX|` → super like overlay (blue)

### Button Press → Card Animation

When a button is tapped, the card animates off-screen programmatically (not via gesture). Use the same snap spring config as gesture-driven swipes. The `isAnimating` guard prevents gesture input during this animation.

Sequence:
1. Button tap → set `isAnimating = true`
2. `translateX.value = withSpring(targetX, snapConfig)` or `translateY.value` for super like
3. On animation complete callback → call `runOnJS(handleSwipe)(direction)` → advance card → reset shared values → set `isAnimating = false`

### Next Card Scale Animation

As the current card moves toward the commit threshold, the next card scales from 0.94 → 1.0 and opacity from 0.7 → 1.0. This runs as a derived animation from `translateX` / `translateY` of the current card.

```
nextCardProgress = clamp(abs(translation) / commitThreshold, 0, 1)
nextCardScale = 0.94 + (nextCardProgress * 0.06)
nextCardOpacity = 0.7 + (nextCardProgress * 0.3)
```

### DestinationEditor Modal Animation

- Entry: `translateY` from `screenHeight * 0.75` → 0, `withSpring({ stiffness: 350, damping: 40 })`
- Exit: `translateY` from 0 → `screenHeight * 0.75`, `withTiming(300, { easing: Easing.in(Easing.ease) })`
- Backdrop: `opacity` from 0 → 1 `withTiming(200)` on entry; reversed on exit

### Haptics

| Event | Haptic |
|-------|--------|
| Swipe committed (any direction) | `Haptics.impactAsync(ImpactFeedbackStyle.Medium)` |
| Button bar tap (skip/like/super like) | `Haptics.impactAsync(ImpactFeedbackStyle.Light)` |
| Decide Later tap | `Haptics.impactAsync(ImpactFeedbackStyle.Light)` |
| Undo tap | `Haptics.notificationAsync(NotificationFeedbackType.Success)` |
| Destructive confirm (remove tracks) | `Haptics.notificationAsync(NotificationFeedbackType.Warning)` |
| Seek (SegmentNavigator tap) | `Haptics.impactAsync(ImpactFeedbackStyle.Light)` |

All haptic calls wrapped in try/catch — silently ignored if haptics unavailable.

### Accessibility

- All interactive elements have `accessibilityRole` and `accessibilityLabel`
- SwipeCard: `accessibilityRole="none"` (it is gesturable, not a button — the button bar provides the accessible action path)
- ButtonBar buttons: `accessibilityRole="button"`
- DestinationEditor rows: `accessibilityRole="checkbox"`, `accessibilityState={{ checked: isSelected }}`
- Scope pills: `accessibilityRole="radio"`, `accessibilityState={{ selected: isActive }}`
- Minimum touch target: 44×44dp on all interactive elements

## 6. Dark/Light Theme Boundary

The swipe screen (`app/(app)/swipe/[playlistId].tsx`) is the only Phase 2 screen. It uses the dark palette defined in this spec.

All screens added in Phase 1 (login, source picker, destination picker) retain their light theme:

| Screen | Background | Text |
|--------|-----------|------|
| Login | `#FFFFFF` | `#111111` |
| Source Picker | `#F9FAFB` | `#111111` |
| Destination Picker | `#F9FAFB` | `#111111` |
| **Swipe Screen** | **`#111111`** | **`#FFFFFF`** |
| **DestinationEditor modal** | **`#1C1C1E`** | **`#FFFFFF`** |

The navigation header for the swipe screen must be styled dark. Use Expo Router's Stack screen options:

```typescript
<Stack.Screen
  name="swipe/[playlistId]"
  options={{
    headerStyle: { backgroundColor: '#111111' },
    headerTintColor: '#FFFFFF',
    headerTitle: '', // empty — playlist name shown in card or elsewhere
    headerBackVisible: true,
  }}
/>
```
